## Module Guide

#### Pattern Intelligence Module

**What it does:** Provides step-by-step guidance for pattern drafting and garment construction.

**When to use:**
- Creating patterns from scratch
- Learning measurement techniques
- Understanding garment construction
- Grading patterns

**Example queries:**
```
"How do I draft a basic bodice pattern?"
"What measurements do I need for a skirt?"
"Explain how to create a sleeve pattern"
"How do I grade a pattern up one size?"
```

**Sample conversation:**
```
You: How do I draft a basic skirt pattern?

Guru: **Skirt Pattern Guidance**

**Required Measurements:**
  • Waist
  • Hip
  • Length

**Estimated Time:** 2-3 hours
**Difficulty Level:** Beginner

**Step-by-Step Process:**
1. Measure waist and hip circumference
2. Determine desired length
3. Calculate fabric requirements
4. Draft pattern based on skirt type
5. Add waistband and closures

**Common Skirt Types:**
  • A-Line
  • Pencil
  • Circle
  • Gathered

💡 **Pro Tip:** Always make a muslin first!
```

#### Troubleshooting Companion Module

**What it does:** Diagnoses and solves sewing and fit problems in real-time.

**When to use:**
- Experiencing fit issues
- Sewing machine problems
- Construction challenges
- Fabric handling difficulties

**Example queries:**
```
"My dress is pulling across the bust"
"Why are my seams puckering?"
"How do I fix a gaping neckline?"
"My fabric keeps slipping while I sew"
```

**Sample conversation:**
```
You: My seams are puckering. What's wrong?

Guru: **Troubleshooting: Puckered Seams**

**Symptoms:**
  • Wavy seams
  • Gathered appearance
  • Poor finish

**Common Causes:**
  • Thread tension too tight
  • Fabric stretching while sewing
  • Wrong stitch length

**Solutions (Try in Order):**
1. Reduce upper thread tension
2. Use proper presser foot pressure
3. Don't pull fabric while sewing
4. Increase stitch length for lightweight fabrics
5. Use tissue paper under fabric

**Difficulty Level:** Beginner

💡 **Pro Tip:** Always test on scrap fabric first!
```

## CLI-Specific Features

### Commands

- `exit` or `quit` - End session
- `help` - Get help
- `clear` - Clear conversation history

### Session Continuity

Your conversation context is maintained throughout a CLI session but clears when you exit.

## API-Specific Features

When using the API, conversation context persists across sessions using user_id.

```python
# Delete context to start fresh
requests.delete(f"{BASE_URL}/context/{user_id}")
```

## Troubleshooting

### Bot doesn't understand my question

Try rephrasing with more specific keywords:
- Use garment names (dress, pants, jacket)
- Mention specific techniques (draping, pattern drafting)
- Include context (season, occasion, skill level)

### Responses are too technical/simple

Specify your skill level in your question:
"As a beginner..."
"I'm intermediate level..."
"Give me advanced details on..."

### Want to start over

In CLI: Type `exit` and restart
In API: Delete your context via API
